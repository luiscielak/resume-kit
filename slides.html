A tailored resume is a system, not a file

Luis Cielak → MIS → design → The Hooman Loop + Cursor Philly

Why this matters

One generic resume is an artifact. A tailored one is a system you can rerun.

  • You keep one source of truth
  • You rewrite it per job, on purpose
  • You never start from a blank page again

The one rule

Do not invent experience

The agent may

  • reorder
  • cut
  • rephrase

It may not add

  • an employer
  • a date
  • a tool
  • a metric
