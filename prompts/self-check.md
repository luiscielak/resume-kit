# Self-check this resume

Compare the tailored resume to the base resume and report anything the tailored version claims that the base does not support. Do not rewrite the resume.

## What to attach

- `resume/base.md`
- the tailored file, for example `applications/business-systems-analyst/resume.md`

## Rules

- List every employer, title, date, tool, number, or metric in the tailored resume that does not appear in the base resume.
- For each one, quote the line and say whether to cut it or rephrase it back to what the base supports.
- Call out any bullet that implies a result the base resume does not state.
- Do not edit any file. Report only.

## Output

A short list. If nothing was invented, say so in one line.
