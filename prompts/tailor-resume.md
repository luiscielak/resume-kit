# Tailor this resume

Help a student rewrite a resume for one job.

## Rules

- Use only facts that already appear in the base resume.
- Do not add employers, dates, tools, degrees, or metrics.
- You may reorder, cut, and rephrase.
- Rewrite the summary and at least three bullets so they use the job's language.
- Keep the same section structure as the base resume.
- Keep it to one page.

## Output

Write the tailored resume as markdown. Do not include a commentary section in that file.
